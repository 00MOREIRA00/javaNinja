# Poliformismo e Abstração

Abstração é um conceito fundamental de programação orientada a objetos que refere-se a capacidade de esconder os detalhes de implementação.
Exemplo: Classe básico é abstrato e o pai de classe complexo. Logo complexo recebe tudo que básico tem. Logo, op que importa é a classes complexo.
